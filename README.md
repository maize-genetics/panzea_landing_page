# panzea.org <img src="src/assets/brand/panzea.svg" align="right" width="120" alt="TASSEL logo">

This is the website for Panzea (the Maize Diversity Project). It is built with
[Astro](https://astro.build) and hosted on GitHub Pages. It replaces the old Wix
site, and all the old links still work.

## Quickstart

You need [Node.js](https://nodejs.org) installed.

```bash
npm ci
npm run dev
```

Then open http://localhost:4321 in your browser.

## Common commands

| Command           | What it does                         |
| ----------------- | ------------------------------------ |
| `npm run dev`     | Start the site locally               |
| `npm run build`   | Build the site into `dist/`          |
| `npm run preview` | Show the built site locally          |
| `npm run verify`  | Check that all links and PDFs work   |

## Publishing

Every push to `main` builds and publishes the site automatically.
