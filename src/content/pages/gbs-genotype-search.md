This search tool can be used to obtain a subset of public genotypes from the current build of our very large maize GBS genotypic data set. Both raw (unimputed) and imputed genotypes are available. The search allows you to specify a chromosomal region and/or taxa (sample) subset of interest.

A similar search tool for non-GBS genotypes (maize HapMap, SNP50, or original NAM SNPs) is available [here](/genotype-search).

To download flat files containing complete GBS data sets for all chromosomes and public taxa, go [here](/genotypes).
