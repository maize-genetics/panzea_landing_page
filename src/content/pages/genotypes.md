From this page you can obtain the latest public "flat file" versions of prepackaged, genotypic data sets. All of these can be opened with the TASSEL 5 (GUI or command line). The genotypes were obtained by whole genome sequencing ("HapMap"), GBS, or with MaizeSNP5O chip or traditional SNP assays.

If any of the links don't work, try right clicking on the link and opening in a new tab.
